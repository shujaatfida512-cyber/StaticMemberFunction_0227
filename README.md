# Constructors, Destructors & Static Members — C++

A collection of C++ exercises focused on **object lifecycle and advanced class features**.

## Topics Covered
- Default constructors
- Parameterized constructors
- Constructor overloading
- Destructors
- Static data members
- Static member functions
- Dynamic arrays
- Function chaining
- The `this` pointer
- Dynamic memory management

## Purpose
This repository documents practical exercises for understanding how C++ classes create, manage, and release objects.
